# キャラクターアクションチャレンジ

**ゲーム名：** キャラクターアクションチャレンジ
**制作者：** 山本

---

## 【ゲーム概要】

アクションアイコンを並べて「プログラム」を作り、キャラクター（ネコ）をゴールの旗まで導くパズルゲームです。
リアルタイムにキャラクターを操作するのではなく、「どう動けばゴールできるか」を先に考えて行動の順番を組み立てるので、プログラミング的思考（順序・試行錯誤・デバッグ）が身につきます。

- 対象：幼児~大人、プログラミング未経験者（展示会での利用を想定）
- モード：やさしいモード 5コース ＋ ふつうモード 5コース（全10コース）
- 1回のプログラムは最大50アクション

### アクション一覧

| アイコン | アクション | 動き |
|---|---|---|
| ← / → | 左へ / 右へ | 1マス移動し、その方向を向く。足場がなければ落ちる |
| ↑ | 上へ | はしごをのぼる |
| ↓ | 下へ | はしごをおりる。木の床の上では、床をすりぬけて下の階へおりる |
| ? | ジャンプ | 向いている方向へ2マス先までとぶ（1段の高さものぼれる） |
| ? | 上へジャンプ（ふつうモードのみ） | まっすぐ上に3マスまでとぶ。木の床はすりぬけて上の階へ上がれる |
| ? | しゃがむ | ひくい天井の下をくぐれる。外に出ると自動で立つ |
| ? | 攻撃 | 前の木箱・てきをこわす |
| ?? | 爆弾 | 前のひびわれ岩・ばくだんだるなどをこわす |

### ステージのしかけ

木箱／てき／トゲ／あな／ひくい天井／ひびわれ岩／はしご／ばくだんだる／木の床／石の床／旗（ゴール）

### 成功・失敗

- 成功：キャラクターが旗に到達すると「CLEAR!」
- 失敗：トゲ・てき・ばくだんだるにさわる、あなに落ちる、全アクションを実行してもゴールできない

## 【操作方法】

操作はマウス（タッチも可）だけで行えます。

1. **コースを選ぶ**：画面上部で「やさしいモード／ふつうモード」とコース番号を選ぶ
2. **アクションを並べる**：「アクションを選ぶ」のアイコンをクリックすると、「アクションプログラム」の最後に追加される
3. **削除する**：プログラム内のアイコンを「ここにドラッグして削除」エリアへドラッグ／「1つ消す」ボタンで最後の1つを削除
4. **並べかえる**：プログラム内のアイコンをドラッグし、「ここへ」の枠が出た位置で放す
5. **スタート**：「? スタート」を押すと左から順に実行。実行中のアイコンが黄色く光る
6. **結果**
   - クリア時：「つぎのコースへ」で次のコースへ進む
   - 失敗時：「プログラムをなおす」（プログラムを残してやり直し）／「さいしょから」（全部消してやり直し）
7. **リセット**：プログラムを空にし、ステージを最初の状態に戻す

その他

- 「遊び方」ボタン：ルールとステージのしかけの説明を表示
- 「音 ON/OFF」ボタン：効果音の切りかえ
- 「ゴール地点」ボタン：ゴールの旗を光らせて場所を示す
- キーボード操作：プログラム内のアイコンを選んで Delete キーで削除、Alt＋←/→ で入れかえ、Esc でダイアログを閉じる

## 【起動方法】

1. `character-action.html` を任意のフォルダに保存する
2. ファイルをダブルクリックしてブラウザで開く

- サーバー、インストール、ビルド作業は不要です（`file://` で直接動作します）
- 推奨ブラウザ：Google Chrome / Microsoft Edge（最新版）
- 展示会では F11 キーで全画面表示にすると見やすくなります
- インターネット接続がなくても遊べます（オフライン時はWebフォントの代わりにPC内の丸ゴシック系などのフォントで表示されます）

## 【使用技術】

- HTML5
- CSS3（Grid / Flexbox、CSSアニメーション、レスポンシブ対応）
- JavaScript（ES2020、ライブラリ・フレームワーク不使用）
  - HTML Canvas 2D：ステージ・キャラクター・エフェクトの描画（画像ファイル不使用、すべてコードで描画）
  - Pointer Events：ドラッグによる削除・並べかえ（マウス／タッチ両対応）
  - Web Animations API：並べかえ時のスライドアニメーション
  - Web Audio API：効果音（音声ファイル不使用、コードで生成）
  - localStorage：クリア済みコースと最後に遊んだコースの記録
- Google Fonts「M PLUS Rounded 1c」（オンライン時のみ読み込み）
- サーバーサイド（PHP・DB等）は不使用

## 【統合時の注意事項】

他のゲームやポータルサイトに組み込む場合は、以下に注意してください。

### 組み込み方法

- **推奨は `<iframe>` での埋め込み**です。CSS・イベントが他のページと干渉しません。

  ```html
  <iframe src="character-action.html" title="キャラクターアクションチャレンジ"
          style="width:100%; height:1000px; border:0;"></iframe>
  ```

- 画面幅に合わせてレイアウトが変わるため、iframe の幅は 1000px 以上を推奨します（最小でも約400px幅で表示できます）。

### 同じページに直接貼り付ける場合

- **CSSクラス名に接頭辞がありません。** `.app` `.panel` `.modal` `.stage` `.slot` `.start` `.reset` などの汎用名を使っているため、他のCSSと衝突する可能性があります。必要に応じて接頭辞（例：`cac-`）を付けて置換してください。
- `:root` にCSS変数（`--bg` `--blue` `--green` など）を定義し、`body` の背景色・フォントも設定しています。
- **HTMLの `id` も汎用名です**（`game` `stock` `palette` `startBtn` `resetBtn` `result` `help` など）。重複しないよう確認してください。
- JavaScriptは即時関数（IIFE）で囲んでおり、グローバル変数は作りません。ただし次のイベントを `window` / `document` に登録しています。
  - `window`：`pointermove` / `pointerup` / `pointercancel`（ドラッグ処理）
  - `document`：`keydown`（Esc でダイアログを閉じる）
- 結果・遊び方のダイアログは `position:fixed; z-index:100`、ドラッグ中のアイコンは `z-index:60` です。
- `[hidden]{display:none!important}` を全体に適用しています。

### 保存データ（localStorage）

| キー | 内容 |
|---|---|
| `cac-cleared` | クリア済みコースIDの配列（例：`["e1","e2","n1"]`） |
| `cac-course` | 最後に選んだコースID |

- コースID：やさしいモード `e1`?`e5`、ふつうモード `n1`?`n5`
- 記録は「ブラウザごと・同じ保存場所（オリジン）ごと」に保存されます。設置場所（URL）が変わると記録は引き継がれません。
- 来場者ごとに記録をリセットしたい場合は、上記キーを削除するか、ブラウザのシークレットウィンドウで起動してください。
- localStorage が使えない環境でもゲームは動作します（記録が残らないだけです）。

### その他

- 効果音は、ブラウザの仕様により最初のクリック後から鳴ります。
- Google Fonts への通信を避けたい場合は、ファイル先頭の `<link ... fonts.googleapis.com ...>` の3行を削除してください（代替フォントで表示されます）。
- ファイル末尾の `window.claude?.hot` を参照するコードは、公開環境でのホットリロード用です。存在しない環境では何もしないので、そのままで問題ありません（削除も可）。
- コースの追加・変更は、JavaScript内の `COURSES` 配列を編集します。各コースは24列×9行の文字列マップで定義しています。

  | 文字 | 意味 | 文字 | 意味 |
  |---|---|---|---|
  | `.` | 空間 | `P` | スタート位置 |
  | `G` | ゴール（旗） | `#` | 土と草 |
  | `S` | 石ブロック・石の床 | `F` | 木の床 |
  | `=` | 浮き足場 | `C` | 木箱 |
  | `R` | ひびわれ岩 | `L` | ひくい天井 |
  | `H` | はしご | `^` | トゲ |
  | `E` | てき | `B` | ばくだんだる |

  最下段の地面（7?8行目）を `.` にすると「あな」になります。
